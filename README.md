## 🎮 Gameplay Overview

**ESCAPE THE VTU** is an addictive retro endless runner developed in **HTML5 Canvas, React, TypeScript, and Tailwind CSS**. 

Take control of a determined engineering student sprinting across campus to escape the clutches of VTU exams, assignment deadlines, and attendance shortages.

- **100% Offline & Pure Web Audio**: Synthesized 8-bit chiptune loop and arcade SFX via Web Audio API. Zero external audio file dependencies.
- **Dynamic Meme Engine**: Hilarious college memes pop up during gameplay and on the Game Over screen.
- **Progressive Difficulty**: Gradually scales through semesters:
  1. **Sem 1**: First Semester (Paced survival)
  2. **Sem 2**: Assignment Pressure
  3. **Sem 3**: Internal Exams (Faster obstacles)
  4. **Sem 4**: Semester Examination
  5. **Sem 5**: Backlog Era (M1 Backlog Monsters)
  6. **Sem 8**: VTU Survival Mode (Hyper-speed chaos)

## ⚠️ Engineering Hazards (Obstacles)

* **Ground Hazards (JUMP)**:
  * 📚 **Assignment Stack**: Thick spiral record books with red submission flags.
  * 👨‍🏫 **Angry Professor**: Walking stick, red pen, and strict detention stares.
  * 📝 **Surprise Internal Exam (IA-1)**: Sudden pop test papers with ticking clocks.
  * 🧮 **Scientific Calculator**: Scientific fx-991ES flashing `SYNTAX ERROR`.
  * 👾 **Backlog Monster**: Fuzzy purple glitch creature representing M1 (Maths).

* **Overhead Hazards (SLIDE)**:
  * 🚨 **75% Attendance Shortage Notice**: Suspended detention banners — duck underneath!
  * 🌐 **VTU Result 504 Crash**: Gateway Timeout dialog boxes floating in the air.
  * ⏰ **11:59 PM Submission Deadline**: Flashing digital clock countdowns.

## ☕ Survival Supplies (Collectibles)

* ☕ **Canteen Coffee**: 4 seconds of invincible turbo speed with obstacle smashing power.
* 📚 **Topper Notes**: +150 bonus points immediately added to your semester score.
* 💻 **StackOverflow Laptop**: Generates a cyan shield orb that absorbs 1 collision hit.
* 🎓 **85% Attendance Card**: +200 bonus score & guaranteed examination hall ticket.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/shreyasMH26/escape-the-vtu.git

# Enter the project directory
cd escape-the-vtu

# Install dependencies
npm install

# Start development server
npm run dev
```

Build for production:
```bash
npm run build
```
